Guide

导入教程

按设备选择导入或订阅方式。

Windows
  1. 下载 .ics 文件
  2. 右键选择打开方式
  3. 选择日历应用导入
iOS
  1. 设置 -> 日历 -> 账户
  2. 添加账户 -> 其他
  3. 添加已订阅的日历
1 / 6
Apple 官方教程
macOS
  1. 打开“日历”App
  2. 点击菜单栏的 “文件” > “新建日历订阅”
  3. 输入订阅链接
  4. 完善日历信息
1 / 4
Apple 官方教程
Outlook Web
  1. 打开 outlook.live.com/calendar
  2. 添加日历 -> 从 Web 订阅
  3. 输入订阅链接
打开 Outlook
